# AI-enabled Web Application

This is Experiment 4 for the Artificial Intelligence on Cloud Computing lab.

## Files
- `app.py` — Streamlit web application
- `requirements.txt` — Python dependency list

## Run locally
```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## Deploy
Push these files to a public GitHub repository, then deploy the repository on Streamlit Community Cloud using `app.py` as the main file.
